Patina source transpiles to Rust, then compiles to a native binary via rustc. You get Rust's speed, safety, and zero-cost abstractions — without the syntax tax.

Why Patina?

No semicolons

Newlines end statements. Write code, not punctuation.

Simple types

int, float, string, bool — not i64, f64, String.

String interpolation

"{name} is {age}" — expressions inside strings, no macros.

No lifetimes

The transpiler handles borrowing. You just write code.

50+ builtins

sqrt, split, map, read_file, input — batteries included.

Native speed

Compiles to machine code through Rust. No GC, no runtime.

Traits & generics

Full Rust-style polymorphism with cleaner syntax.

# comments

Python-style comments. ** for power. range() for loops.

Patina vs Rust

What Patina Rust
Variable var x = 5 let x: i64 = 5;
Mutable mut x = 5 let mut x = 5;
Print println("hi {x}") println!("hi {}", x);
Input input("Name: ") stdin().read_line(…)
Types int, float, string i64, f64, String
Power x ** 2 x.pow(2)
Class class Point { ... } struct Point { ... }
Methods methods Point { ... } impl Point { ... }
Imports use std.io use std::io;
Semicolons never everywhere
Lifetimes never 'a everywhere

Traits & Generics

trait Shape {
    fn area(self) -> float
    fn name(self) -> string {
        return "shape"
    }
}

fn print_area<T: Shape>(s: T) {
    println("{s.name()} has area {s.area()}")
}

methods Shape for Circle {
    fn area(self) -> float {
        return PI * self.radius ** 2
    }
    fn name(self) -> string {
        return "circle"
    }
}

Get Started

You need Rust installed (rustup.rs). Then:

$ git clone https://github.com/user/patina && cd patina
$ cargo build --release
$ ./target/release/patina hello.pa --run

Or run directly with cargo run -- file.pa --run during development.
